# Multiplayer roadmap

Cíl: 10–30 hráčů v jednom sdíleném světě, oddělené party instance Akasuzuki.

## Milníky
1. Import původního v134 a ověření parity klienta.
2. Oddělení rendering/UI od simulace a herních dat.
3. Node.js/TypeScript server, WebSocket protokol, synchronizace dvou hráčů.
4. Serverově autoritativní pohyb, HP, combat a AI.
5. PostgreSQL: účty, postavy, inventář, EXP a account bonusy.
6. Akasuzuki instance pro 2–4 hráče; reconnect a bezpečné odměny.
7. Zátěžové testy 10–30 uživatelů.

Bez testů a importovaných herních souborů se žádný milník nepovažuje za hotový. Hlavní release singleplayeru se nemění.
